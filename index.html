How I work

Scrum sprints with AI agents inside every stage. Decisions stay with people; drafting, building, checking and documenting go to agents.

  1. 1

    Discover

    Me
    Customer interviews, journey mapping, metrics review
    Agent
    Turns interview notes and analytics into findings
  2. 2

    Specify

    Me
    Scope, priorities, trade-offs
    Agent
    Drafts the PRD, user stories and acceptance criteria
  3. 3

    Build

    Me
    Unblocks the team, clarifies edge cases
    Agent
    Writes and refactors code with engineers, builds prototypes
  4. 4

    Review

    Me
    Accepts work against the criteria
    Agent
    Reviews code, generates tests, flags regressions
  5. 5

    Release

    Me
    Release plan, go/no-go, stakeholder update
    Agent
    Release notes, changelog, updated docs
  6. 6

    Measure

    Me
    KPIs, retro, next sprint's focus
    Agent
    Pulls reports, summarises anomalies

Measure feeds the next sprint's discovery
